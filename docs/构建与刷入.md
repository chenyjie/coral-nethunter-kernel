# 构建与刷入

## 0. 目录约定

`<root>` 表示 AOSP 的 `kernel/build` 布局根目录：

```
<root>/
├── build/                          # AOSP kernel/build
├── prebuilts/                      # Google prebuilts clang r416183b
├── private/msm-google/             # 内核源码树
├── private/msm-google-modules/     # 外部模块源码（qcacld-3.0 / fts touch）
├── nethunter.config                # ← 来自本仓库 config/
└── build.config.nethunter-cfi      # ← 来自本仓库 config/
```

## 1. 环境

主机依赖（Ubuntu）：

```
git curl python3 bison flex bc build-essential libssl-dev libelf-dev \
libncurses-dev zip unzip rsync cpio kmod lz4 device-tree-compiler
```

另需 `repo` 工具。

| 项目 | 要求 |
|---|---|
| 工具链 | Android clang **r416183b**（≈12.0.5）+ LLD 12.0.5 |
| 交叉工具链 | `aarch64-linux-android-4.9` |
| defconfig | `floral_defconfig` |
| 磁盘 | 源码 + 工具链约 20–25 GB，`out/` 30–40 GB，建议留 100 GB |
| 内存 | 16 GB 及格，32 GB 舒服 |

> WSL2 也可以，但源码要放在 WSL 自己的 ext4 里（如 `~/kernel`），不要放 `/mnt/e`。

## 2. 源码与子模块

```bash
git clone https://github.com/0xSoul24/kernel_google_msm-4.14 -b cnb private/msm-google
```

KernelSU 子模块要**完整克隆**并切到 `v4.2.0-rc2`：

```bash
cd private/msm-google
git submodule update --init --recursive          # 不要加 --depth 1
cd KernelSU && git fetch --tags && git checkout v4.2.0-rc2
git rev-list --count HEAD                        # 应为 4444 → 版本号 30000+4444+700 = 35144
```

## 3. 打补丁

```bash
cd private/msm-google
git apply ../patches/0001-clang-target-aarch64-linux-gnu.patch   # 必打
git apply ../patches/0002-kpanic-logger.patch                    # 可选，见 docs/技术说明.md §5
cp ../src/kpanic_logger.c drivers/misc/
```

`patches/optional/0003` 在本配置下不参与编译（`#ifdef CONFIG_KSU_MANUAL_HOOK`），如无需要不必应用。

## 4. 放配置

```bash
cp config/build.config.nethunter-cfi  <root>/build.config.nethunter-cfi
cp config/nethunter.config            <root>/nethunter.config
```

`nethunter.config` 的语法由 `build.config.nethunter-cfi` 里的 `nethunter_config()` 解释：

| 写法 | 含义 |
|---|---|
| `FOO` | 打开（`scripts/config -e`） |
| `-FOO` | 关闭（`scripts/config -d`），用来覆盖 defconfig 里的 choice |
| `FOO=1` / `FOO=y` | 设值（`scripts/config --set-val`），数值型符号必须这样写 |
| `#` 开头 | 注释 |

末尾自动执行一次 `olddefconfig` 让依赖收敛。

## 5. 编译

```bash
cd <root>
BUILD_CONFIG=build.config.nethunter-cfi ./build/build.sh 2>&1 | tee build-$(date +%F-%H%M).log
```

两点约定：

- `BUILD_CONFIG` **必须是相对 `<root>` 的路径**。`build/_setup_env.sh` 里是 `. ${ROOT_DIR}/${BUILD_CONFIG}`，绝对路径会被拼错而找不到文件。
- LTO 的 `vmlinux.o` 阶段是单线程 `ld.lld`，日志几十秒不增长属正常，通常跑 20–50 分钟。判断进度看进程 CPU 时间，不要看日志长度。

产物在 `out/android-msm-pixel-4.14/dist/`：

```
Image.lz4   System.map   vmlinux   dtbo.img   modules.load   *.ko
```

## 6. 打包（AnyKernel3）

脚本用 `src/anykernel.sh`（`do.devicecheck=1`，device.name 为 `coral` / `flame` / `floral`，`do.modules=0`，`do.systemless=1`）。

```bash
cp out/android-msm-pixel-4.14/dist/Image.lz4 anykernel3/Image.lz4
cd anykernel3 && zip -r9 ../kernel-nethunter-coral-$(date +%Y%m%d).zip . -x '.git/*'
```

## 7. 拼 boot 镜像（可选，用于 `fastboot boot` 先验）

以原装 `boot.img` 为模板，只替换内核段并同步 `kernel_size`；ramdisk 与 dtb（`d00dfeed` 魔数，999,136 字节）原样保留，各段偏移按 4096 对齐。也可以用 `magiskboot`：

```bash
magiskboot unpack boot_a_template.img
cp Image.lz4 kernel
magiskboot repack boot_a_template.img boot_new.img
```

`magiskboot repack` 会按分区大小把镜像补到 64 MB，按 boot header 裁到精确长度即可，裁点之后应为零填充。

> `fastboot boot` 对原装模板镜像可直接用（不落盘）；对自搓的 boot.img 可能只打印 `Sending OKAY` 而不启动，这种情况改用 `fastboot flash`。

## 8. 刷入

```bash
# 备份当前 boot
adb shell "su -c 'dd if=/dev/block/by-name/boot_a of=/data/local/tmp/boot_a_before.img'"
adb pull /data/local/tmp/boot_a_before.img .

# 先验，不落盘
adb reboot bootloader
fastboot devices
fastboot boot boot_gnu_cfiperm.img

# 确认能开机后落盘
fastboot flash boot boot_gnu_cfiperm.img
fastboot reboot
```

或直接用 AnyKernel3 包（KernelFlasher / ReSukiSU）。

## 9. 验证

```bash
adb shell "cat /proc/version"                                  # 4.14.357-0xSoul-g26277ea9b0ce-dirty
adb shell "uname -r"
adb shell "su -M -c id"                                        # uid=0
adb shell "su -M -c 'zcat /proc/config.gz | grep -E \"MAC80211=|88XXAU=|QCA_CLD_WLAN=|CFI_PERMISSIVE\"'"
adb shell "su -M -c 'ls /sys/module/mac80211 /sys/module/cfg80211'"
adb shell "su -M -c 'ip -br link'"                             # 插 OTG 网卡后出现 wlan1
adb shell "su -M -c 'ls /config/usb_gadget/g1/functions/'"     # hid.usb0 / hid.usb1 → BadUSB
adb shell "su -c 'aireplay-ng --test wlan1'"                   # 外置网卡注入实测
```

## 10. 回退

```bash
fastboot flash boot boot_a_before.img
fastboot reboot
```

刷之前备份 boot 分区，原装备份在本地与手机（`/data/local/tmp/`、`/sdcard/`）各留一份。
